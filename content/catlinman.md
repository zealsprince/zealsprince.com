# The name before this one

Catlinman was my handle for most of a decade. I retired it in 2020 and everything since has been zealsprince, but a good deal of the work people know me for still sits under the old name, and pretending otherwise would leave a hole where the interesting part is.

[catlinman.com](https://catlinman.com) is still up as an archive. This page is the short version.

## NekoRoX

The foobar2000 theme lived here. A fork of CaTRoX built out into a full configuration with custom panels, bundled plugins and a dark interface that worked the moment you installed it. It is still the most-starred thing I have put on GitHub, and it picked up a fork of its own in AlphaRoX.

It is no longer maintained, and it did not really end so much as move. It became [rox](/rox/).

## Code from that era

- **campdown**, a Bandcamp downloader and library tool that quietly picked up more users than anything else I wrote at the time
- **love2dconsole** and **love2dfluid**, an in-application console and a fluid dynamics system for the LÖVE2D game framework
- A long tail of themes, dotfiles, IRC bots and Advent of Code repositories in whichever language I felt like that December

Most of it is archived rather than maintained. It stays public because deleting your own history is a strange thing to do.
